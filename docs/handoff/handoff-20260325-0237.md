## Key Decisions Made

| Decision | Rationale | Alternatives Considered |
|---|---|---|
| `data/repositories/` package (6 files) instead of one fat file | One class per aggregate, easy to extend | Single `repositories.py` (already existed, would grow) |
| `BaseTaskService` shared helpers (not mixin, not utils module) | Services already class-based; inheritance is natural | Module-level functions; Protocol/mixin |
| LLM client cached by (provider, model, ollama_url) key | Settings can change at startup only; key captures all variance | Singleton pattern (would break tests) |
| `SpatialConfig` dataclass singleton | Immutable by default, IDE-friendly, no YAML overhead | Plain dict, env vars per value |
| Adaptive thresholds fix: in-place `elem['spatial_level']` update | Minimal diff; keeps existing pipeline shape | Re-run full `predict_hierarchy_spatial` pass |
| TEACHER default role (not LIBRARIAN) | Lower friction for most users; librarians are a smaller privileged group | Keep LIBRARIAN default |
| Admin sees LIBRARIAN docs (not all docs) | Requirement spec: "admin nhìn được hết các tài liệu của các nhân viên thư viện đã up" | Admin sees everything |

## Important Notes

- **JWT warning is expected** in dev — the validator intentionally `warns` (not raises)
  when `JWT_SECRET_KEY` is the default value. Set `JWT_SECRET_KEY` env var in production.

- **`spatial_config.py` is a singleton** — `spatial_config = SpatialConfig()` at module level.
  All spatial modules import from it. To override for testing:
  ```python
  from config.spatial_config import spatial_config
  spatial_config.gap_threshold_percentile = 50  # temporary override
  ```

- **Two thinning systems** are intentionally kept separate:
  - `TreeOptimizer.thin_tree()` (pageindex) — **semantic** (merges small-token tree nodes)
  - `hierarchical_thinning()` (spatial) — **layout** (merges OCR text lines into paragraphs)

- **`OcrExtractor.page_result`** — callers that previously relied on the tuple return
  `(elements, page_result)` from `extract_page()` must switch to `extractor.page_result`
  attribute after the call.

- **Document ownership**: `Document.user_id` is `nullable=True` in the DB schema.
  Documents with `user_id=NULL` are not visible to any non-admin user via the list endpoint.
