## Key Architecture Notes

| Topic | Detail |
|-------|--------|
| Two pipelines | `/ocr` = original scanned path; `/extract` = new unified path (routes internally to OCR for scanned pages) |
| DOCX fast-path trigger | `if not any(e.get('bbox_x1', 0) for e in elements)` → skips spatial scoring, uses `heading_level` directly |
| Non-ASCII Windows paths | `doc_converter.py` falls back to `C:\Temp` when `TEMP` dir contains non-ASCII (e.g. `C:\Users\Duy''`) |
| Text-box DOCX | `DocxExtractor` uses direct XML walking (`body.findall`) — `doc.paragraphs` misses `wps:txbx` content |
| pdfplumber dedup | Spans overlapping table bboxes suppressed from PyMuPDF output to avoid duplicate text |
